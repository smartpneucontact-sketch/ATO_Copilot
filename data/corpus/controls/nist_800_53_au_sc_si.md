# NIST SP 800-53 — Audit (AU), System Communications (SC), System Integrity (SI) Summary

**Synthetic demo document — abbreviated for ATO triage.**

## AU-2 Audit Events
- Identify the types of events the system is capable of logging.
- Coordinate logging activity with incident response.

**Applicability for ATO**: HIGH — every system in scope.

## AU-3 Content of Audit Records
- Audit records must contain timestamp, source, user, action, outcome, affected resource.

## AU-12 Audit Generation
- Audit records generated by all auditable events.
- Records forwarded to SIEM (Splunk) per enterprise log management policy.

**Applicability for ATO**: HIGH for any system processing Confidential or higher data.

---

## SC-7 Boundary Protection
- Monitor and control communications at external boundaries and key internal boundaries.

**Applicability for ATO**: HIGH for any system with internet-facing components.

## SC-8 Transmission Confidentiality and Integrity
- Protect confidentiality + integrity of transmitted information. TLS 1.2 minimum.

**Applicability for ATO**: HIGH for every networked system.

## SC-13 Cryptographic Protection
- Use cryptography conforming to FIPS 140-2 (or 140-3) validated modules.
- Approved algorithms only (AES-256, RSA-2048+, SHA-256+).

**Applicability for ATO**: HIGH for any system processing Confidential or higher; mandatory for client funds data.

## SC-28 Protection of Information at Rest
- Encryption at rest required for Confidential data and above. KMS-managed keys.

**Applicability for ATO**: HIGH for any persistence layer holding Confidential+ data.

---

## SI-2 Flaw Remediation
- Identify, report, and correct system flaws.
- Patch management within SLA: critical 7d, high 30d, medium 90d.

## SI-4 System Monitoring
- Monitor the system to detect attacks, unauthorized connections, and indicators of compromise.
- Feed monitoring data to SOC / SIEM.

**Applicability for ATO**: HIGH for any production system.

## SI-7 Software, Firmware, and Information Integrity
- Detect unauthorized changes to software, firmware, and information. SBOM required for new ATOs.

**Applicability for ATO**: HIGH for any system handling client-facing transactions.
